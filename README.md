# Java Learning Repository

A structured collection of Java programs and notes covering Core Java, Object-Oriented Programming, Collections, I/O, Exception Handling, and beginner DSA practice.

## Structure

```text
java.demo/
├── 01-Basics/
├── 02-Arrays/
├── 03-Collections/
├── 04-OOP/
├── 05-IO/
├── 06-Exceptions/
├── 07-Programs/
├── 08-DSA/
└── 09-Notes/
```

## Topics Covered

- Java fundamentals, data types, input, loops, and methods
- Arrays and `java.util.Arrays`
- ArrayList, LinkedList, HashMap, Set, Stack, and Queue
- Classes, inheritance, encapsulation, method overloading, and overriding
- BufferedReader and file handling
- Exception handling with try/catch, throw, and related examples
- Number programs and programming practice
- Two-pointer and basic DSA problems
- Java and OOP study notes

## Running Programs

Use a Java JDK and compile individual source files:

```bash
javac path/to/FileName.java
java FileName
```

Some files are standalone practice programs and may use different class names, so run them individually.

## Notes

Compiled `.class` files and IDE/Jupyter-generated files are ignored for future commits through `.gitignore`. Existing compiled artifacts from the learning history are retained where they remain part of the repository history.

This repository documents my Java learning and practice journey, from fundamentals toward backend development and DSA.
