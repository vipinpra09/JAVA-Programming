# Java Learning Repository

A structured collection of Java programs, practice code, DSA problems, OOP examples, collections, exception handling, file I/O, and study notes.

This repository contains my Java learning journey, from core syntax and programming fundamentals to data structures and object-oriented programming.

## Repository Structure

```text
java.demo/
├── 01-Basics/          # Java fundamentals, input, methods, loops, data types
├── 02-Arrays/          # Array programs and Arrays utility practice
├── 03-Collections/     # ArrayList, LinkedList, HashMap, Set, Stack, Queue
├── 04-OOP/             # Classes, inheritance, overloading, overriding, OOP examples
├── 05-IO/              # BufferedReader and file handling
├── 06-Exceptions/      # Exception handling examples
├── 07-Programs/        # Practice and number-based programs
├── 08-DSA/             # Two-pointer and array/DSA practice
└── 09-Notes/           # Java/OOP notes and reference material
```

## How to Run

Compile a Java file:

```bash
javac path/to/FileName.java
```

Run the compiled class:

```bash
java FileName
```

> Some older practice files may use different class names or contain experimental code. Compile and run them individually.
