| isLeapYear              | date.isLeapYear()                              | Check if leap year                   |
| plusDays                | date.plusDays(n)                               | Add days                             |
| plusWeeks               | date.plusWeeks(n)                              | Add weeks                            |
| plusMonths              | date.plusMonths(n)                             | Add months                            |
| plusYears               | date.plusYears(n)                              | Add years                             |

| isEqual                 | date1.isEqual(date2)                           | Compare if dates are equal           |
| until                   | date1.until(date2)                             | Difference as Period                  |
| format                  | date.format(DateTimeFormatter)                 | Format date to String                 |
| toString                | date.toString()                                | Default String representation         |
